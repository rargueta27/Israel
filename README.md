# Legacy of Sheldon and Miriam Adelson

This project is a web-based tribute documenting the lives and contributions of Sheldon and Miriam Adelson.

## 📂 Project Contents
* **Biographical Pages**: Dedicated HTML files for Sheldon and Miriam Adelson.
* **Media Gallery**: A collection of videos (.mp4) and images documenting their history and impact.
* **Donations**: Information regarding their philanthropic efforts.

## 🛠️ Built With
* HTML5
* CSS3 (Custom styling via `style.css`)
